# Example structures

These are deposited RCSB PDB example structures used only in marketing previews.
They are not results generated by BioGen AI. Each file includes chain A and the
original title/secondary-structure records; other chains are omitted for a small,
fast-loading interactive preview.

Sources (downloaded 2026-09-24):
- https://files.rcsb.org/download/1EMA.pdb
- https://files.rcsb.org/download/4N5T.pdb
- https://files.rcsb.org/download/1CRN.pdb
- https://files.rcsb.org/download/6MRR.pdb
- https://files.rcsb.org/download/1UBQ.pdb

The viewer links directly to the source structure's RCSB entry.
